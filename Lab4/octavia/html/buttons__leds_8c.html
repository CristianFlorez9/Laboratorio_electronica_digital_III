Detailed Description

Driver de botones (con antirrebote) y LEDs de Octavia.

Los flancos de los botones se capturan por interrupción de GPIO. La ISR deshabilita el pin, guarda el instante del flanco y lo marca como pendiente; el antirrebote y la generación de eventos se hacen en bl_actualizar(), que espera BL_ANTIRREBOTE_MS desde ese instante y luego confirma el nivel leído. Las funciones públicas están documentadas en buttons_leds.h.

Function Documentation

◆ bl_actualizar()

void bl_actualizar ( void )

Valida los botones pendientes una vez cumplido el antirrebote.

Debe llamarse de forma periódica desde el lazo principal. La ISR de GPIO guarda el instante del primer flanco de cada botón; esta función confirma el cambio cuando han transcurrido BL_ANTIRREBOTE_MS desde ese instante, medido con time_us_32(), por lo que el antirrebote no depende del periodo del lazo (solo se añade el retraso con que se vuelva a llamar). No bloquea y retorna de inmediato si no hay botones pendientes.

Note
Modifica variables compartidas con la ISR de GPIO.

◆ bl_iniciar()

void bl_iniciar ( void )

Configura GPIO, interrupciones de flanco y estado inicial.

Toma el estado de los botones al arrancar como estable (sin eventos falsos), registra la callback de GPIO y habilita IO_IRQ_BANK0. La octava inicial es 0.

Note
La interrupción de GPIO queda asociada al núcleo que llama a esta función. Llamarla una sola vez, antes de iniciar el SysTick.

ISR de GPIO: marca el botón como pendiente de validación.

No valida nada: deshabilita las interrupciones del pin (para ignorar el rebote), guarda el instante del flanco y agrega el botón a pendientes. La validación se hace en bl_actualizar().
