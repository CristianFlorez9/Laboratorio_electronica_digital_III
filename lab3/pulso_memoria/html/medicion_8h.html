Detailed Description

Utilidades para medir el tiempo de ejecución (en microsegundos) de las funciones del juego.

Se mide con time_us_32() (resolución de 1 us; el desbordamiento cada ~71 min no afecta porque solo se usan diferencias sin signo). Para desactivar TODA la medición basta con poner MEDIR_TIEMPOS en 0: los helpers quedan vacíos y los printf de medición desaparecen.
